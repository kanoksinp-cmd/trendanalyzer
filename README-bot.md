# บอทเซิร์ฟเวอร์ 24 ชม. (GitHub Actions)

บอทนี้รันบน GitHub ทุก 5 นาที **ไม่ต้องเปิดเว็บหรือเปิดคอมค้างไว้** แล้วส่งสัญญาณเข้า Telegram
ใช้กฎชุดเดียวกับหน้าเว็บ: ยืนยันเมื่อปิดแท่ง · กรองเทรนด์ TF ใหญ่ · งดเทรดตอนตลาดทองปิด · งดเทรดช่วงข่าวแรง USD
และติดตามผลว่าแต่ละสัญญาณชน TP หรือ SL แล้วส่งผลให้ด้วย

## ติดตั้ง (ครั้งเดียว ~5 นาที)

1. อัปโหลด 2 ไฟล์นี้เข้า repo เดิม (ต้องอยู่ตำแหน่งเดียวกันเป๊ะ)
   - `bot/bot.js`
   - `.github/workflows/trend-bot.yml`
   (ใน GitHub กด Add file → Create new file แล้วพิมพ์ชื่อพร้อม path เช่น `.github/workflows/trend-bot.yml` แล้ววางเนื้อหา)
2. ไปที่ repo → **Settings → Secrets and variables → Actions**
   - แท็บ **Secrets** → New repository secret
     - `TG_TOKEN` = Bot Token จาก @BotFather
     - `TG_CHAT` = Chat ID (ตัวเดียวกับที่ใช้ในหน้าเว็บ)
   - แท็บ **Variables** (ไม่ใส่ก็ได้ จะใช้ค่าในวงเล็บ)
     | ชื่อ | ความหมาย | ค่าเริ่มต้น |
     |---|---|---|
     | `ASSET` | GOLD, BTCUSDT, ETHUSDT ... | GOLD |
     | `TF` | 5m, 15m, 1h, 4h | 15m |
     | `HORIZON` | ทายล่วงหน้ากี่แท่ง | 3 |
     | `SPEED` | normal / fast / turbo | normal |
     | `MODE` | strict / stat | strict |
     | `HTF_MODE` | block / align / off | block |
     | `NEWS_BLOCK` | on / off | on |
     | `OFFSET` | ปรับราคาให้ตรงโบรกเกอร์ (ทอง) | 0 |
     | `ACC_BAL` | เงินทุน (ใส่แล้วจะคำนวณ lot ให้) | — |
     | `ACC_CUR` | THB / USD | THB |
     | `FX` | USD/THB | 33 |
     | `RISK_PCT` | เสี่ยงต่อไม้ % | 1 |
     | `SEND_WAIT` | on = แจ้งตอนกลับเป็น "รอ" ด้วย | off |
3. ไปแท็บ **Actions** → เลือก `trend-bot` → **Run workflow** เพื่อทดสอบ
   ถ้าเขียวและ Telegram ได้ข้อความ (หรือ log บอกว่า WAIT) แปลว่าใช้ได้ หลังจากนั้นจะรันเองทุก 5 นาที

## ข้อควรรู้
- GitHub อาจรันช้ากว่ากำหนด 5–15 นาทีช่วงคนใช้เยอะ จึงเหมาะกับ TF 15 นาทีขึ้นไป ไม่เหมาะกับ 1–5 นาที
- repo สาธารณะ: ใช้ Actions ฟรีไม่จำกัด · Token อยู่ใน Secrets ปลอดภัย ไม่มีใครเห็น
- GitHub จะ**หยุดรันอัตโนมัติถ้า repo ไม่มีการเปลี่ยนแปลง 60 วัน** (จะมีอีเมลเตือน) แค่กด Enable ใหม่ในแท็บ Actions
- ถ้าเห็น error `HTTP 451` แปลว่า Binance บล็อกเซิร์ฟเวอร์สหรัฐ บอทลองหลายโดเมนให้แล้ว ถ้ายังไม่ได้แจ้งได้
- บอทไม่ใช้ "โทนหัวข่าว" เหมือนหน้าเว็บ (ใช้แค่ปฏิทินข่าวแรง) เพื่อให้ผลทดสอบย้อนหลังกับของจริงตรงกัน
